# Security policy

## Supported versions

Only the latest release receives fixes; installed apps offer updates in-app.

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately through GitHub:
[Security → Report a vulnerability](https://github.com/leonseemann/openseries/security/advisories/new).

Include the affected version and OS, steps to reproduce and the impact you expect. You will get a
reply within a week; once a fix is released, the advisory is published with credit to you unless
you prefer otherwise.

Of particular interest: the in-app updater and its signature check, the installers, the virtual
audio drivers, and anything that sends data to devices.
